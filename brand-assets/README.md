# ZC-OCW Official Brand Assets & Design Guidelines

This directory contains the official vector artwork, logos, certificate templates, and graphic patterns for **Zewail City OpenCourseWare (ZC-OCW)**.

---

## 📁 Directory Structure

```text
brand-assets/
├── logo-new/
│   ├── ocw-logo-primary.png      # High-resolution master transparent PNG (591×591)
│   └── ocw-logo-primary.ai       # Adobe Illustrator vector master file
├── logo-legacy/
│   ├── ocw-logo-legacy.png       # Original 2017 foundation logo
│   └── ocw-logo-legacy.ai        # Legacy vector artwork
├── zc-logo/
│   ├── zc-emblem.png             # Zewail City University emblem (transparent)
│   └── zc-emblem.ai              # University emblem vector master
├── templates/
│   ├── ocw-certificate-sample.jpg# High-resolution (300 DPI) certificate preview
│   └── ocw-certificate-template.ai# Editable vector certificate layout
└── patterns/
    └── ocw-graphic-patterns.ai   # Brand background geometry and patterns
```

## 🛡️ Usage Guidelines

- **Primary Logo (`logo-new/`)**: Use on all active web interfaces, YouTube video watermarks, thumbnails, and official social media posts.
- **Transparency**: Always prefer `.png` with transparent background when overlaying on dynamic themes or backgrounds.
- **Vector Assets (`.ai`)**: Use Adobe Illustrator, Affinity Designer, or Inkscape for high-resolution print banners, merchandise, or certificate generation.
